# 인블로그(inblog) 세팅 가이드 — 문강금은

홈페이지가 매일 2건 발행하는 글(오늘의 금시세 리포트 + 가이드/제품/동향)을 인블로그 블로그에도 자동으로 올리고, 인블로그 글이 홈페이지를 "원문"으로 가리키게(canonical) 만드는 절차입니다. 계정 생성·결제·API 키 발급은 **문강금은 담당자 또는 세느루 담당자가 직접** 진행합니다(비밀번호·결제정보는 대행 불가).

## 0. 준비물

| 항목 | 값 |
|---|---|
| 블로그 주소(서브도메인) | `blog.<홈페이지 도메인>` (도메인 확정 후. 예: blog.munkanggold.com) |
| 도메인 DNS 관리 권한 | 도메인 등록업체 로그인 |
| 인블로그 플랜 | **Team 플랜 이상** — API가 유료 플랜에서만 동작(14일 체험 기간에도 API 사용 가능) |
| 홈페이지 관리자 | `/admin` → 자동발행 → 인블로그 API 키 · 블로그 주소 |

## 1. 계정·블로그 생성 (10분)

1. https://inblog.ai 회원가입 → 블로그 만들기.
2. 블로그 이름: `문강금은 금시세·금 거래 가이드` / 설명: `종로3가 금·은 매입·판매 문강금은이 매일 발행하는 오늘의 금시세 리포트, 금 팔기·골드바 구매 가이드, 돌반지·골드바 제품 소개.` / 언어 ko
3. 로고·파비콘·OG: `public/img/logo.png`, `icon-512.png`, `og.png` 업로드(원본 로고 .ai에서 생성한 파일).
4. 저자 프로필: `문강금은 편집팀` (아바타 `mark.png`). 저자 소개: `종로3가역 11번 출구 앞 금·은 매입·판매 금은방. 매입가·판매가 매일 공개, 30분 정밀 감정, 현장 현금 지급, 출장 매입.` + 홈페이지 링크.
5. **채널 링크(블로그 설정 → 소셜/외부 링크)에 아래를 모두 등록** — 홈페이지 sameAs와 동일하게 맞춰 엔티티 신호를 통일합니다.
   - 홈페이지: (도메인 확정 후)
   - 유튜브: https://www.youtube.com/@munkanggold
   - 네이버 플레이스: https://map.naver.com/p/entry/place/2049757349?placePath=%2Fhome
   - 인스타그램: https://www.instagram.com/munkanggold
   - 네이버 블로그: https://blog.naver.com/lallapaloza
   - Threads: https://www.threads.com/@munkanggold
   - 카카오 오픈채팅: https://open.kakao.com/o/pZJxBomi
6. 대시보드 → 설정 → 요금제에서 Team 플랜 결제(담당자 직접).

## 2. 커스텀 도메인 연결 (DNS 전파 최대 24시간)

1. 대시보드 → 설정 → **커스텀 도메인** → "서브도메인" → `blog.` 뒤에 홈페이지 도메인 입력 → 연결 시작.
2. 화면에 표시되는 DNS 레코드(CNAME)를 **그대로** 도메인 등록업체 DNS에 추가(값은 계정마다 발급되므로 화면 값을 복사).
3. 대시보드에서 "연결 완료" 확인 → SSL 자동 발급.
4. CLI: `npm i -g @inblog/cli` → `inblog auth login --api-key` → `inblog blogs domain connect blog.<도메인>`.

## 3. API 키 발급 → 홈페이지 연결 (5분)

1. 대시보드 → 설정 → **API 키** → 새 키 발급(이름: `munkang-site`). 한 번만 표시되므로 복사.
2. 홈페이지 `/admin` → 자동발행 → **인블로그 API 키** 붙여넣기, **블로그 주소** 입력(`https://blog.<도메인>`), 발행 시 전송 ON → 저장. (또는 Railway 환경변수 `INBLOG_API_KEY`)
3. **연결 테스트** 클릭 → 블로그 이름·플랜이 뜨면 성공.
4. 콘텐츠 메뉴에서 글 하나를 골라 **인블로그 전송** → 인블로그 대시보드에 나타나는지 확인. 이후 자동발행 글은 발행과 동시에 전송됩니다.

전송 규칙: 제목·본문·meta description·FAQ JSON-LD를 함께 보내고 `canonical_url`을 홈페이지 원문(`/blog/slug`)으로 지정합니다. 본문 말미에 원문 링크와 오늘의 금시세 페이지 링크가 자동 삽입됩니다. 글을 초안으로 내리면 인블로그에서도 비공개 처리됩니다. 전송 실패는 콘텐츠 목록에 "오류"로 표시되며 재전송 버튼으로 다시 보냅니다.

## 4. 검색엔진 등록

1. **구글 서치콘솔**: URL 접두어 `https://blog.<도메인>` → HTML 태그 → 인블로그 대시보드 SEO 설정에 붙여넣기 → 확인 → 사이트맵 제출.
2. **네이버 서치어드바이저**: 소유확인 메타태그 등록 → 사이트맵 제출 → "수집 요청".
3. 홈페이지도 동일: `/admin` → 설정 → 네이버·구글 소유확인 값 입력 → `https://<도메인>/sitemap.xml` 제출.

## 5. 상호 연결(sameAs)·채널 통일

- 홈페이지 설정에 인블로그 주소를 넣으면 Organization 스키마 `sameAs`·푸터·블로그 목록에 자동 반영됩니다.
- 네이버 플레이스·인스타·유튜브·네이버 블로그 프로필의 "웹사이트" 항목에 홈페이지 주소를, 인블로그에는 위 채널 전부를 넣어 **모든 채널이 서로를 가리키게** 합니다(NAP 통일: 상호·주소·전화 010-5005-8636 / 0507-1403-8636).
- 인블로그 글 하단 CTA: `금 매입·구매 예약 → /apply`가 기본 전송됩니다.

## 6. 발행 후 점검(주 1회)

- 인블로그 대시보드 → 콘텐츠 성과: 노출·클릭 상위 글.
- 홈페이지 `/admin` → 기술 감사·방문: AI 크롤러(OAI-SearchBot·PerplexityBot·Claude-User) 방문 추이.
- 주간 리포트에 인블로그 동기화 건수와 오류 건수가 자동 집계됩니다.
