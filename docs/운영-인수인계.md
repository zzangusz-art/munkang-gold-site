# 운영 인수인계 — 문강금은 홈페이지 관리자

대상: 문강금은 시세 담당 · 세느루 운영 담당. 관리자 주소 `/admin` (기본 admin / munkang1234! → 첫 로그인 후 변경).

## 매일 아침 (2분) — 오늘 시세 입력

세 가지 방식 중 하나를 고르면 됩니다. 저장 즉시 홈 시세판·시세표·계산기·제품 가격·llms.txt가 바뀌고 이력이 쌓입니다.

1. **직접 입력(권장)**: 관리자 → **시세 관리** → 매입가·판매가 칸에 오늘 고시가 입력 → 「시세 저장」. 단위는 원/돈(3.75g).
2. **엑셀**: 「엑셀 양식(현재 값)」 다운로드 → 값 수정 → 「엑셀 업로드」 → 미리보기 확인 → 반영.
3. **국제시세 자동 계산**: 시세 관리 → 국제 시세 카드에서 매입/판매 스프레드(%)를 매장 정책에 맞게 넣고 「매일 자동 갱신」 체크. 08:30·13:30에 국제 금값(USD/oz)×환율로 순금·22K·18K·14K·은·백금 시세가 자동 반영됩니다. 참고 표시만 원하면 체크 해제.

시세를 하루 이상 안 바꾸면 기술 감사의 "시세 갱신 3일 이내" 항목이 미충족으로 표시됩니다.

## 매일 — 예약·문의 확인

- 좌측 **예약·문의** 메뉴의 빨간 숫자가 미처리 건수. 구분(팔기/구매/출장/상담)·품목·중량·연락처를 보고 전화한 뒤 상태(신규→연락함→완료)와 메모를 남기면 주간 리포트에 집계됩니다.
- 홈페이지 우측 버튼(오픈채팅·전화·카톡ID·예약)과 모바일 하단 바로 들어오는 상담은 각 채널에서 직접 응대합니다.

## 주 1회 — 콘텐츠 검토

- **콘텐츠(블로그)**: 매일 09:00 「오늘의 금시세 리포트」(월요일은 주간), 15:00 가이드/제품/동향 글이 자동 발행됩니다. 제목을 훑어보고 사실과 다르면 「편집」 또는 「내리기」.
- 검토 후 발행 방식으로 바꾸려면 자동발행 → 「생성 즉시 발행」 해제(초안 저장).
- **제품 관리**: 골드바·돌반지 등 20개 초기 제품의 공임·마진·뱃지·이미지를 실제에 맞게 수정. 사진은 「편집」에서 업로드. 소개글이 없는 제품은 자동발행이 순서대로 채웁니다.
- **공지·후기·유튜브**: 쇼츠 URL과 제목만 넣으면 홈·유튜브 페이지에 VideoObject로 노출. 고객 후기는 게재 동의를 받은 것만 등록(별점·구분).

## 리포트 (매주 자동, 전후 스크린샷 포함)

- 착수일(2026-09-15, 화요일) 기준 매주 화요일 08:30에 지난주 주간 리포트가 자동 생성됩니다(기술 감사·전후 스크린샷 캡처 포함). 4주차가 끝나면 월간 종합 리포트가 추가됩니다.
- **리포트·스크린샷** 메뉴에서 HTML 열기(인쇄 → PDF) 또는 DOCX 다운로드. 클라이언트 전달용은 DOCX.
- 리포트 0번 섹션에 **전후 비교 이미지**가 자동으로 들어갑니다. 이전 = 착수 전 기존 온라인 채널(당근 업체 프로필·Threads 시세 게시, 또는 설정의 "기존 홈페이지" 주소), 이후 = 신규 홈페이지 최신 캡처 + 관리자 4화면.
- 서버에 크롬이 없는 환경이면 로컬에서 `node scripts/capture.js after https://배포주소` 실행 후 「이미지 업로드」.

## 설정에서 채워야 할 것 (담당자 확인 필요)

- 매장 정보: **상세 주소(건물·층·호)**, 사업자등록번호, 대표자, 이메일, 개인정보보호책임자 → 비어 있으면 화면·구조화데이터에서 생략됩니다.
- 사이트 URL: 도메인 확정 후 반드시 변경(canonical·sitemap·JSON-LD 기준).
- 네이버 서치어드바이저·구글 서치콘솔 소유확인 값, GA4 ID.
- LLM API 키(Anthropic 권장): 없으면 가이드·동향 글은 생성되지 않고 시세 리포트·제품 소개(템플릿)만 발행됩니다.
- 인블로그 API 키·블로그 주소: `docs/인블로그-세팅-가이드.md`.

## 문제가 생기면

| 증상 | 확인 |
|---|---|
| 자동발행이 안 됨 | 자동발행 → 최근 실행의 failed 사유. LLM 키 없음이면 가이드·동향 불가(시세 리포트·제품 소개만) |
| 국제시세 미조회 | 시세 관리 → 「지금 조회」. 무료 API(gold-api.com, open.er-api.com) 장애면 마지막 값 유지 |
| 인블로그 오류 | 콘텐츠 목록 "오류" 마우스오버 → 대부분 플랜(Team 이상)·키 만료 |
| 제품 가격이 이상함 | 제품 편집의 공임·마진·시세 코드(au999/ag999) 확인. 고정가를 넣으면 시세와 무관 |
| 사이트가 옛 버전으로 보임 | Ctrl+F5. 정적 파일은 배포 시각 도장이 붙어 자동 갱신 |
